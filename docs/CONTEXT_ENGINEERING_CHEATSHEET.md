**Cheat Sheet**

| | | |
|---|---|---|
| *Type* | *Description* | *Example* |
| State intent | Give direction without requesting action | *"I'm working on X, here is what I want to accomplish"* |
| Authorize context expansion | Explicitly name and authorize what enters context | *"read ./FOO.md"* |
| Correct understanding | Actively correct misframing before it propagates | *"that framing is wrong because..."* |
| Provide feedback | Orient without requesting action | *"this draft is good," "Direction 1 is strong"* |
| Guide actions | Offer direction for approval | *"I propose we move this to..."* |
| Approval | Explicit authorization of a named action | *"proceed"* |
| Request discussion | Separate thinking from action | *"share ideas, no writes"* |
| Verify understanding | Check what the tool derived, not what it did | *"Explain your understanding of ..."* |
| Sanity check | Ask explicitly for what is in context. Never assume.| *"Give a summary of what is currently in context"* |
